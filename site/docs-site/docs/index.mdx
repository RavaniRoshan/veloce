# Introduction

Veloce is an application framework for terminal user interfaces in Rust. If
you have built apps with Next.js or Remix, the mental model transfers
directly: you declare **routes** that render **views**, views declare their
**data dependencies**, and the framework owns everything in between.

## Choose your path

  install to running dashboard, verifiable at every step.

- **Understand** — [Explanation](/explanation/architecture): why the framework

## How it works, in thirty seconds

- **Routes** map paths to views. `VeloceApp` holds the stack: push, pop,
  replace. The root route cannot be popped.
- **Views** are structs implementing `load`, `fallback`, `update`, `view`,
  and `handle_key`.
- **Actions** are your enum. State changes only inside `update`; background
  work reports back through a dispatcher — never a lock.
- **Layout** is flexbox. Nest `Flex`, `Text`, `Spacer`; taffy computes the
  geometry and Veloce snaps it to terminal cells.
- **Runtime** restores the terminal on panic, `Ctrl-C`, and normal exit.
