# Introduction

Veloce is an application framework for terminal user interfaces in Rust. If
you have built apps with Next.js or Remix, the mental model transfers
directly: you declare **routes** that render **views**, views declare their
**data dependencies**, and the framework owns everything in between — the
event loop, the layout math, and the terminal itself.

You will like Veloce if you are building dashboards, forms, log viewers,
deployment monitors, or agent harnesses that live in the terminal — and you
would rather describe screens than orchestrate threads, channels, and escape
codes.

## How it works

- **Routes** map paths to views. `VeloceApp` holds the stack: push, pop,
  replace. The root route cannot be popped.
- **Views** are structs that implement five methods: `load`, `fallback`,
  `update`, `view`, and `handle_key`.
- **Actions** are your enum. State changes only inside `update`, and
  background work reports back through a dispatcher — never a lock.
- **Layout** is flexbox. You nest `Flex`, `Text`, and `Spacer`; taffy
  computes the geometry and Veloce snaps it to terminal cells.
- **Runtime** restores the terminal on panic, `Ctrl-C`, and normal exit.
