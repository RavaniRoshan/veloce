# Veloce documentation

Veloce is an opinionated application-layer framework for terminal UIs in Rust.
It feels like Next.js/Remix to a web developer and like idiomatic Rust to a
systems developer: a stack router, declarative views with async hydration,
taffy-backed flexbox layout, and a frame-budgeted render loop.

- **Design** — the 70-line design note: contract, AST shape, quantization, threading.
- **Checklist** — every requirement with its proof (test name or measured probe).
- **Progress** — milestone log with measured runs.
- **Decisions** — every judgment call, recorded.
- **Parity** — capabilities deliberately deferred.

> Every claim in these docs is backed by a named test or a measured probe.
> Anything unverified is labeled UNVERIFIED.
