Send like Remix. Own the terminal.

Router & shells

Stack routing with persistent chrome, modal overlays with backdrops, and focus lock — the same mental model you bring from Next.js/Remix.

True flexbox

taffy computes continuous layout; Veloce quantizes into discrete terminal cells with error diffusion, parent clamps, and no zero-width collapses.

Managed async hydration

Views declare load(); the framework runs it on Tokio, shows your fallback, and cancels dangling tasks on navigation.

Crash-resilient runtime

Every panic, SIGINT, and SIGTERM restores the terminal. Logs go to a file, never the live screen.

One event loop

Block-free ingestion thread, tokio pool, and a synchronous main thread with priority drain: input > actions > ticks.

60 FPS budget

Dirty-state redraws, a frame-budgeted flush, and benchmarked cold boot ~3.5 ms / idle RSS ~4 MiB.

The reference API. That’s the whole app.

#[async_trait::async_trait] impl View for DeploymentDashboard { type Action = Action; async fn load(&mut self) -> Result<()> { ... } fn update(&mut self, action: Action, cx: &mut Context<Action>) { match action { Action::LogReceived(line) => self.logs.push(line), ... } } fn view(&self) -> Element { Flex::column().gap(1) .child(Text::new("Service: auth-service-v2").bold()) .child(ScrollView::new().flex_grow(1.0) .children(self.logs.iter().map(|l| Text::new(l)))) .into_element() } } #[tokio::main] async fn main() -> Result<()> { VeloceApp::new().route("/", DeploymentDashboard::default()).run().await }

Three steps, install to first frame.

  1. Add veloce = "0.1" to Cargo.toml.
  2. Implement View for one struct with flexbox children.
  3. Run it: VeloceApp::new().route("/", view).run().await
